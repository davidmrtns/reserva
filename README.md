## Descrição do projeto
Este projeto é uma aplicação web de e-commerce desenvolvida com Django, inspirada na marca brasileira [Reserva](https://www.usereserva.com/). A plataforma simula a experiência de uma loja online completa, permitindo que usuários explorem produtos, filtrem opções, montem carrinhos e finalizem compras por meio da integração com o Mercado Pago.

Além da experiência para o cliente, a aplicação também oferece um painel administrativo para gerenciamento de produtos, estoque e pedidos.

## Funcionalidades
- 🧾 Visualização de produtos disponíveis na loja;
- 🔎 Filtros por tamanho, tipo de produto e faixa de preço;
- 🛒 Criação de carrinhos com múltiplos itens;
- 💳 Finalização de compras com integração ao **Mercado Pago**;
- ⚙️ Painel administrativo para gerenciar produtos e pedidos.

## Desenvolvimento
### Tecnologias utilizadas
- **Backend/Frontend**: Django;
- **Banco de dados**: SQLAlchemy.
