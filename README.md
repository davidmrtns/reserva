## Descrição do projeto
Este projeto é um e-commerce inspirado na [Reserva](https://www.usereserva.com/) e desenvolvido em Django.

## Funcionalidades
- Visualizar produtos;
- Filtrar produtos da loja por tamanho, tipo e preço;
- Montar carrinhos com diversos produtos;
- Efetuar compras (a partir de integração com o Mercado Pago);
- Administrar os produtos exibidos ao público e compras realizadas.

## Desenvolvimento
### Status do projeto
O projeto está finalizado.

### Tecnologias utilizadas
- Backend e Frontend: Django;
- Banco de Dados: SQLAlchemy.
